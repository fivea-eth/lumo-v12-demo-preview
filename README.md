Public GitHub Pages build of the manually accepted LUMO V12 interactive 720p demo.

- Scope: static visual and interaction preview.
- Included: accepted W01 720p hero Pilot, K01 poster, retained hero fallback, assembly media, responsive interface, purchase-decision information, Ownership, FAQ, a disabled checkout preview, and complete English/Simplified Chinese browsing.
